# SIPL Toolkit

![CI](https://github.com/valeriyalera/sipl-toolkit/actions/workflows/ci.yml/badge.svg?branch=main)

Інструментарій для синтаксичного аналізу, виконання, трасування, візуалізації та автоматичної побудови денотаційної семантики програм мовою **Simple Imperative Programming Language (SIPL)** (курс «Теорія програмування», КНУ імені Тараса Шевченка).

---

## Обрані ID завдань та заявлена кількість балів

| ID завдання | Модуль / Функціонал | Заявлені бали | Статус |
| :--- | :--- | :---: | :---: |
| **CORE (Parser / Eval / Trace)** | БНФ-граматика SIPL (LALR), побудова типізованого AST з координатами (`SourceSpan`), інтерпретатор великих кроків із лімітом ітерацій та покроковий трасувальник виконання | *База* | Виконано |
| **VIS-01** | Візуалізація конкретного дерева синтаксичного виводу (Parse Tree / CST) у нетерміналах курсу (`P`, `S`, `Aexp`, `Bexp`) у форматах Text, JSON, Graphviz DOT та SVG | **1.5** | Виконано |
| **SEM-01** | Автоматична рекурсивна побудова семантичного терму з AST у нотації курсу (`AS^x`, `WH`, `IF`, `S^1`, `S^2`, `·`, `id`) з децукруванням розширень та golden-тестами | **2.0** | Виконано |
| **REL-01** | Налаштування CI/CD у GitHub Actions: автоматичний лінтинг (`ruff`), перевірка типів (`mypy`), модульні тести (`pytest --cov`) та збірка дистрибутива (`build`) | **0.5** | Виконано |
| **Разом (додаткові модулі)** | | **4.0** | **Готово до здачі** |

## Архітектура проєкту

```text
sipl-toolkit/
├── .github/workflows/ci.yml   # GitHub Actions CI (lint, mypy, pytest, build)
├── grammar/sipl.lark          # Формальна граматика SIPL
├── examples/                  # Приклади програм мовою SIPL
├── src/sipl/
│   ├── ast_nodes.py           # Вузол AST та серіалізація
│   ├── parser.py              # LALR-парсер і трансформер AST
│   ├── interpreter.py         # Операційна семантика виконання (Eval)
│   ├── tracer.py              # Покроковий трасувальник станів (Trace)
│   ├── visualizer.py          # Побудова та рендеринг дерева виводу (VIS-01)
│   ├── semantics.py           # Побудова семантичних термів курсу (SEM-01)
│   └── cli.py                 # Інтерфейс командного рядка (CLI)
└── tests/                     # Набір модульних та golden-тестів
