# SIPL Toolkit

![CI](https://github.com/valeriyalera/sipl-toolkit/actions/workflows/ci.yml/badge.svg)

Інструментарій для мови Simple Imperative Programming Language (SIPL): парсер, інтерпретатор, трасувальник, побудова дерева виводу (CST) та семантичних термів у нотації курсу «Теорія програмування».
